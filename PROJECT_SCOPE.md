# Project scope and source alignment

This codebase is for **KISAN X**. Uploaded files with a KRISHIQ filename are treated as team handbooks for the same project, consistent with the user's clarification that the names were file-naming mistakes.

This package implements the four-person team's **Member 4** backend/data-integration/decision-engine handoff: NASA connector and normalization, farm profile service, crop/rotation catalogue loading, hard-constraint and preference comparison, what-if reruns, explainability/report storage, API tests, and integration contract.

It also follows the KISAN-X master blueprint's recommended Python/FastAPI backend. The master blueprint describes a wider 21-feature platform, three teams, and six tasks. This ZIP does not claim to implement the entire platform; it provides the Member 4 backend slice and leaves shared interfaces ready for the other team members' modules.
